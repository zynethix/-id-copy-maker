# 身份证复印件生成器（id-copy-maker）需求文档

## 1. 定位
- 只给产品所有者自己用：电脑上选本地图片，手机上选图或拍照。
- 只处理已有图片，不调用相机 API。
- 纯本地离线处理，隐私优先，任何情况下图片都不离开用户设备。

## 2. 交付形态
- 单个 `index.html`，原生 JS，零依赖，不用构建工具和框架。
- 电脑双击本地文件即可使用。
- 同一份文件可部署成网站给手机使用，不做 PWA，网站版只有一个 `index.html`。
- 浏览器范围：iOS Safari 16 及以上，Android Chrome 最近两个大版本，电脑端 Chrome、Edge、Safari 最近版本。更老的浏览器打开时给提示，不保证可用。

## 3. 主流程（单页完成，不跳页）
1. 选正面（人像面）图，用固定比例框裁剪，确认。
2. 选反面（国徽面）图，同上。可以只做一面。
3. 水印设置。
4. 版面预览，下方有"导出颜色"选项（灰度、彩色，互斥）。
5. 导出，以及"清除全部"。

每一步的状态都显示在页面上。

## 4. 裁剪
- 裁剪框固定 85.6:54 比例，初始为图片内能放下的最大框并居中，不能拖出图片范围。
- 拖框内部整体移动，拖角点等比缩放，角点不能单独拖动变形。
- 只做裁剪，不做透视矫正。身份证是否在框内、是否居中，由用户为校准效果负责。
- 手机端拖角点时在手指上方显示放大镜。
- 提供"旋转 90°"按钮，不提供任意角度微调。
- 输出固定 1011×638 像素（300 DPI）。图片比它小就放大，同时触发"画质不足"警告。
- 歪的照片不强制重拍：裁剪步骤放一条固定提示，建议重拍或换一张正的图，用户仍可继续上传和导出。不做自动歪斜检测。

## 5. 图片边界情况
- 超大图：长边超过 4000 像素的先缩到 4000 以内，避免手机浏览器内存撑爆。
- EXIF 方向：依赖浏览器按 EXIF 自动纠正，旋转按钮兜底。
- HEIC 格式：解码失败时给出明确错误提示。
- 画质不足：短边不足 600 像素时给警告，不阻止导出。
- 不做图像增强（亮度、对比度、去阴影），拍得不清楚就重拍。

## 6. 版面与导出
- A4 竖版，正面在上半页，反面在下半页，水平居中，两张之间约 30mm。
- 只选一面时位置不变，另一半留白。
- 每张卡片画 0.3mm 细边框。
- 卡片按真实尺寸 85.6×54mm、1:1 输出。
- PNG 为 2480×3508 像素（300 DPI）。
- PDF 为 210×297mm，由程序自己拼装，嵌入 JPEG（质量 0.92），不引入 PDF 库。
- "导出颜色"位于版面预览下方，两个选项互斥，默认彩色："灰度"对应复印机效果，"彩色"对应原件的彩色效果。
- 预览随所选颜色显示（灰度为黑白复印效果，彩色为原件彩色），导出内容与所选颜色一致。
- 文件名形如 `身份证复印件_20261025.pdf`，不含姓名或证件号码。

## 7. 水印
- 默认开启。用户手动关闭时提示一次。关闭后导出文件里没有水印。
- 只盖在卡片区域，A4 空白处不盖。
- 样式：斜向平铺，灰色，约 30% 透明度，每张卡片内至少出现 2 到 3 行重复文字。
- 用途手填，日期默认今天并可手改。
- 预设模板：
  - 「仅供____办理业务使用，他用无效 日期」
  - 「仅用于租房备案，复印无效 日期」
  - 「仅用于银行开户，复印无效 日期」
  - 自定义
- 水印文字不记忆，每次手填，不使用 localStorage。

## 8. 隐私硬规则
1. 页面无任何网络请求：没有统计、CDN 和外链字体，用 CSP 把 `connect-src` 设为 none。
2. 图片只存在于内存，不写入 localStorage、IndexedDB 或任何缓存。
3. 导出文件不含 EXIF 和 GPS 信息，图片经画布重绘后自然清除。
4. 页面提供"清除全部"按钮，点击后立即清空内存里的图像和预览。
5. 验收时在断网环境下用开发者工具网络面板检查，请求数必须为 0。

## 9. 明确不做（v1）
- 透视矫正和自动边缘检测。
- 自动识别正反面。
- 图像增强。
- PWA 和 Service Worker。
- 记忆水印文字或任何用户输入。
- 调用相机 API（手机拍照通过系统文件选择器完成）。

## 10. 验收标准
1. 电脑断网后能完成从选图到导出的全流程。手机断网只作观察项，不作通过条件，实测结果写进文档。
2. 页面发出的网络请求为 0（开发者工具网络面板）。
3. 导出的 PDF 页面为 210×297mm，每张卡片实际尺寸为 85.6×54mm（误差 ±0.5mm）。
4. 导出的 PNG 为 2480×3508 像素，不含 EXIF 和 GPS 信息。
5. 水印默认开启，关闭时有提示，关闭后导出文件里没有水印。
6. 只选一面和选两面时，布局都正确。
7. 点"清除全部"后，页面上看不到任何图像，也无残留的预览。
8. iOS Safari 和 Android Chrome 上各完整跑一遍，含拍照输入（需要所有者在真机上执行）。
9. 12MP 照片不会让手机浏览器崩溃。

## 11. 待实测事项（当前均未验证）
- CSP 的具体写法：需确保内联脚本和样式可用、图片只允许 `blob:` 和 `data:`、`connect-src` 为 none，实现时用浏览器实测。
- iOS Safari 通过文件选择器选 HEIC 时是否自动转成 JPEG。
- 手机端断网后能否打开网站版页面（不作通过条件）。

## 12. 发布
- 部署到 EdgeOne Pages 属于对外发布。开发完成并通过验收后，再单独向所有者确认一次，不在开发过程中自行部署。
